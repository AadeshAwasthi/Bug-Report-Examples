## Description

Values are accepted and user moves to the Overview page. This is different from the expected behaviour seen with `standard_user` and from normal e-commerce behaviour.

## Steps to Reproduce

1. Open https://www.saucedemo.com
2. Login with `standard_user` / `secret_sauce`
3. Add a product, open cart and click Checkout
4. Enter `12345` in First Name and `@@@@` in Last Name
5. Enter a valid Postal Code and click Continue

## Expected Result

A validation message is shown for invalid name values.

## Actual Result

Values are accepted and user moves to the Overview page.

## Reproducibility

Always (3 out of 3 attempts)

Not attached (behaviour is easy to reproduce with the steps above).
