## Description

A browser alert appears: "Sorting is broken! This error has been reported to Backtrace." Products are not sorted. This is different from the expected behaviour seen with `standard_user` and from normal e-commerce behaviour.

## Steps to Reproduce

1. Open https://www.saucedemo.com
2. Login with `error_user` / `secret_sauce`
3. Select "Name (Z to A)" from the sort dropdown

## Expected Result

Products are sorted in descending alphabetical order.

## Actual Result

A browser alert appears: "Sorting is broken! This error has been reported to Backtrace." Products are not sorted.

## Reproducibility

Always (3 out of 3 attempts)
