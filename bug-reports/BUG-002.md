## Description

Product order does not change. The dropdown still shows "Name (A to Z)". The same steps work correctly with `standard_user`.

## Steps to Reproduce

1. Open https://www.saucedemo.com
2. Login with `problem_user` / `secret_sauce`
3. Select "Price (low to high)" from the sort dropdown
4. Observe the product order

## Expected Result

Products are re-ordered from lowest to highest price.

## Actual Result

Product order does not change. The dropdown still shows "Name (A to Z)".

## Reproducibility

Always (3 out of 3 attempts)
